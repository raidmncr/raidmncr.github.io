Run it locally

No setup is needed. Clone the repository and open index.html in a browser:

bash
git clone https://github.com/raidmncr/raidmncr.github.io.git
cd raidmncr.github.io

In VS Code, the Live Server extension reloads the page as you edit.

Update the site

Edit the files, then push the changes. GitHub Pages republishes within a minute or two.

bash
git add .
git commit -m "Describe your change"
git push
